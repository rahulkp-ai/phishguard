About PhishGuard

ML-POWERED PHISHING DETECTION

PhishGuard uses a Random Forest classifier trained on 100,000+ URLs to detect phishing attacks by analysing 30 structural URL features — no network requests, no DNS lookups, just instant lexical analysis.

Built as a portfolio project demonstrating end-to-end ML: data collection, feature engineering, model training, REST API, and a production-ready web interface.
